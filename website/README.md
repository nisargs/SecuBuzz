# SecuBuzz Web Application

The official website and web platform for [SecuBuzz](https://secubuzz.com) by MiSo Labs. Built with React 18, Vite, Tailwind CSS, TypeScript, and Framer Motion.

## Features
- **Cybersecurity News**: 60-word briefs summarizing verified security disclosures.
- **CISA KEV Advisories**: Known Exploited Vulnerabilities tracking with due dates and ransomware flags.
- **Dark & Light Mode**: Accessible, sober dual-theme design system.
- **Compliance & Legal**: Built-in Privacy Policy, Terms of Service, and Account Deletion flows complying with Google Play standards.

## Development

```bash
# Run local dev server (http://localhost:5173)
npm run dev

# Build for production (outputs to ./dist)
npm run build

# Preview production build
npm run preview
```
